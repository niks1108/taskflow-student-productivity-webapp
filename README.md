# TaskFlow – Student Productivity Workspace

A modern, dark-themed student productivity application built with **React and Firebase** to help students organize tasks, track productivity, and manage their study sessions.

## ✨ Features

- **Kanban Board** – Organize tasks with drag-and-drop.
- **Smart Task Management** – Set priorities, categories, descriptions, and due dates.
- **Productivity Analytics** – Track task completion and productivity.
- **Monthly Calendar** – View and manage upcoming deadlines.
- **Pomodoro Timer** – Stay focused with structured study sessions.
- **AI Planning Assistant** – Get rule-based task planning suggestions.

## 🛠️ Tech Stack

- React.js
- JavaScript
- Firebase Authentication
- Cloud Firestore
- Firebase Hosting
- Vite
- Recharts
- CSS

## 🚀 Getting Started

```bash
git clone YOUR_REPOSITORY_URL
cd taskflow_react
npm install
```

Create a `.env` file using `.env.example` and add your Firebase configuration.

Start the development server:

```bash
npm run dev
```

Create a production build:

```bash
npm run build
```
